# Android candidate artwork

These reversible listing candidates reuse the exact paths and colors in `android/app/src/main/res/drawable/wakestate_mark.xml`, the active Android launcher/splash mark. No app or PWA branding is changed.

- `android-icon-candidate.png`: 512 x 512 RGB PNG, full square background; no baked store corner mask.
- `android-feature-candidate.png`: 1024 x 500 RGB PNG, app name and factual journal subtitle.
- SVG sources are included for editability. Rasterized with CairoSVG, then exported RGB without alpha.

Both PNGs were visually inspected at their full dimensions on September 23, 2026: no clipped text, consistent teal/navy mark, readable contrast and clear spacing. They are candidate artwork, not store-submitted assets or screenshots. The orange-wave PWA icon is intentionally unchanged; cross-platform brand unification is a separate decision. Final listing review must consider the actual Android screenshot set and any current store requirements.
